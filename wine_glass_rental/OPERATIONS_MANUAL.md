# VERREs 事業オペレーション・マニュアル（完全版）

> 本書だけで「予約 → 在庫引当 → 発送 → 利用 → 返送 → 洗浄 → 検品 → 再在庫化」の全工程と、
> 必要な人員・設備・コストを数字で再現できることを目的とした実務マニュアル。
> 通貨はすべて税抜・モデル値。実調達価格・運賃は契約時に更新する前提。

最終更新: 2026-06 / 対象: 創業者・現場オペレーター・出資/融資審査担当

## 0. ビジネスを一言で

「高級ワイングラスを所有せず利用する」サービス。BYO（持込可）飲食店・ケータリング・ホームパーティに、
品種別／ブランド別のグラスを**専用リユースケースで往復配送**。顧客は**洗わず返すだけ**、**通常破損は補償込み**。
同一在庫を**年10〜18回転**させ、1脚あたり累計レンタル料で仕入額を回収する「資産回収型レンタル」。

**儲けの構造（1回の貸出＝Premium 6脚の例）**
売上 ¥9,100 − 変動費 ¥3,678 = **貢献利益 ¥5,422（粗利率59.6%）**。
この貢献利益で固定費（人件費・家賃等）を回収する。→ 第6章・第11章で全ティア分解。

## 2. 予約システム（受注の仕組み）

### 2.1 フェーズ別の構成と費用

| フェーズ | 構成 | 月額 | 狙い |
|---|---|---:|---|
| Phase 1（創業〜） | Shopifyベーシック＋レンタル予約アプリ（在庫カレンダー連動） | ¥3,650＋¥4,000 | 早く安く立上げ |
| Phase 1代替 | STORES/BASE＋予約フォーム | ¥0〜2,980 | 超低コスト |
| Phase 2（軌道後） | レンタル特化SaaS（Booqable等）＋自社LP | $35〜49 | 個体・期間管理の自動化 |
| Phase 3 | Next.js＋Stripe＋Supabaseで自社化（初期¥1,200,000計上） | ホスティング¥3,000 | 手数料圧縮・B2B機能 |

### 2.2 予約フロー（システム要件）

1. **選択**：品種・ティア・脚数・利用日・配送先地域を入力。
2. **空き判定**：利用日を中心に**7日ブロック**（出荷前日＋利用4日＋返送1日＋洗浄バッファ2日のうち重複日）で、
   該当SKUにフリーな**物理セットID**が存在するか在庫カレンダーで判定。
3. **決済**：Stripe / Shopify Payments（手数料3.6%）。高額帯は**保証金（デポジット）方式**も選択可。
4. **引当**：確定で物理セットIDを `reserved` に。**配送ラベルと返送伝票を自動発行**、ピッキングリスト生成。
5. **前処理**：出荷予定日に作業キューへ。

### 2.3 在庫ブロック日数の根拠（1回転 = 暦7日）

| 工程 | 日数 |
|---|---:|
| 出荷（利用前日着のため2日前出荷） | 1 |
| 利用期間 | 3〜4 |
| 返送（顧客→当社） | 1 |
| 洗浄・検品・再梱包バッファ | 1〜2 |
| **合計（1回転）** | **約7日** |

→ 物理1セットの**年間最大回転 ≒ 52回**。実際は需要の曜日偏在（週末集中）で**年10〜18回転**を計画値とする。

## 3. 在庫管理（個体トレーサビリティ）

### 3.1 個体管理

- 1脚ごとに**QRコード**（耐水ラベル/レーザー刻印の管理タグをケース側に付与、グラス本体は無刻印）。
- セットIDで束ね、ステータスを遷移管理。

```
在庫(available) → 予約引当(reserved) → 出荷(shipped) → 利用中(in-use)
   → 返送中(returning) → 受領/洗浄(cleaning) → 検品(QC)
      → ┌ 合格 → 在庫(available)
        └ 破損(broken) → 補充発注 → 入荷検品 → 在庫
```

### 3.2 個体台帳の項目

SKU / 個体ID / 仕入日 / 仕入価格 / 累計回転数 / 累計レンタル料 / 破損履歴 / 最終検品日 / 状態。

### 3.3 KPI と棚卸

- **在庫回転率**（回/月）、**資産回収率**（累計レンタル料 ÷ 仕入額：1.0超で元取れ）。
- 月次棚卸。減価は**3〜4年 or 回転数ベース**（例：300回転で簿価ゼロ）。
- ツール：Phase1=Shopify在庫＋Airtable/Notion個体台帳＋スマホQR、Phase2=Booqable等。

## 5. 洗浄・検品・再生（戻ってきたグラスの扱い & 人の手配）★重点

> 「割れずに高品質で返す」運用がこの事業の心臓部。**人の手配と時間設計**を数字で固定する。

### 5.1 標準作業手順（SOP：1セット6脚あたり）

| 手順 | 内容 | 標準時間 |
|---|---|---:|
| 1. 受領・開梱 | 伝票照合、QRスキャンで `cleaning` に更新、外観一次チェック | 2分 |
| 2. 予洗い | ぬるま湯で口紅・澱を落とす（中性洗剤少量・スポンジは非研磨） | 3分 |
| 3. 本洗浄 | 業務用グラスウォッシャーで**短時間・低温**バッチ洗浄（軟水/RO） | 4分(実作業) |
| 4. すすぎ | RO水ですすぎ、水滴痕を防止 | （3に内包） |
| 5. スチーム＆ポリッシュ | 蒸気を当て、リントフリークロスで**両手ポリッシュ** | 6分 |
| 6. 検品 | ライトボックスで欠け・曇り・匂いを確認、合否判定 | 3分 |
| 7. 再梱包・記録 | ケースに固定、QRで `available`、台帳更新 | 2分 |
| **計** | | **20分/6脚**（≒3.3分/脚） |

- 高級品（Ultra）は手洗い主体で**25分/4脚**。
- 不合格：曇り→再ポリッシュ、欠け→`broken`で除却・補充発注。

### 5.2 必要人員の試算（手配の核心）

- 洗浄人件：**パート時給 ¥1,300**（東京最低賃金を上回る水準）。
- 1セット20分 → **¥1,300 × (20/60) ≒ ¥433/セット**（ユニットエコノミクスの「人件¥450」と整合）。

- **返却は週初（月・火）に集中**。シフトは**ピーク日に厚く**配置（例：月火に各4.5h×1〜2名）。
- 繁忙期の上振れ対策：**シルバー人材センター・短期業務委託**で機動補充。什器洗浄業者との提携も予備手段。
- 採用：求人媒体/地域掲示、定着のため**作業の標準化（このSOP）と検品基準書**を整備。

### 5.3 破損の扱いと引当（数字）

- 破損率の基準値：**1.2%/回・脚**（専用ケースで0.8%を志向、汎用梱包なら3%に悪化）。
- 引当例（ザルト¥9,000・6脚）：¥9,000 × 1.2% × 6 = **¥648/回**を変動費計上。
- 故意・重過失・紛失のみ顧客実費（利用規約に明記）。通常破損は**価格内包**＝最大の購買障壁を除去。
