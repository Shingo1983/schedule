# VERREs — 高級ワイングラス貸出サービス（コンセプト一式）

持込み可の飲食店・ホームパーティ向けに、ロブマイヤー／リーデル／ザルト等の高級グラスを
「指定日に届き、専用容器で洗わず送り返すだけ・破損補償込み」で提供するレンタル事業のコンセプト一式。

## 中身
- `BUSINESS_PLAN.md` — 多角的分析。市場/競合、ユニットエコノミクス、**初期投資（CAPEX）**、
  **ランニングコスト**、損益分岐、**24ヶ月キャッシュフロー分析**、感応度、リスク、ロードマップ、KPI。
- `site/` — 顧客向けWebサイト（静的HTML/CSS/JS。ビルド不要）。
  - ヒーロー、課題訴求、品種別/ブランド別ラインナップ、利用フロー、料金、B2B定期プラン、
    **料金シミュレーター**、予約フォーム（デモ）、FAQ。
- `deck/` — **日本政策投資銀行（DBJ）向け融資プレゼン資料**（全31スライド・HTML）。
  - `deck/index.html` をブラウザで開くと、矢印キー/Spaceで送れるスライドデッキ。`P`キーでPDF印刷。
  - 5ヶ年損益計画、累積キャッシュフロー、損益分岐、感応度、資金使途、**返済計画/DSCR**、
    政策的意義・ESG、リスク、ロードマップ、KPI、付録（前提・用語）まで網羅。
  - `deck/VERREs_DBJ_pitch.pdf` — 上記をPDF化したもの（配布用）。

## サイトの見方
ローカルで `site/index.html` をブラウザで開くだけ（依存なし）。
簡易サーバなら:

```bash
cd wine_glass_rental/site && python3 -m http.server 8080
# http://localhost:8080
```

## 数値について
`BUSINESS_PLAN.md` の金額は意思決定検証用のモデル値です。実際の仕入価格・運賃・需要で更新してください。
