# VERREs — 高級ワイングラス貸出サービス（コンセプト一式）

持込み可の飲食店・ホームパーティ向けに、ロブマイヤー／リーデル／ザルト等の高級グラスを
「指定日に届き、専用容器で洗わず送り返すだけ・破損補償込み」で提供するレンタル事業のコンセプト一式。

  https://raw.githack.com/Shingo1983/schedule/claude/wine-glass-rental-business-1szo0t/wine_glass_rental/deck/index.html

## 中身
- `BUSINESS_PLAN.md` — 多角的分析。市場/競合、ユニットエコノミクス、初期投資、
  ランニングコスト、損益分岐、24ヶ月キャッシュフロー、感応度、リスク、ロードマップ、KPI。
- `OPERATIONS_MANUAL.md` — **オペレーション完全版**。仕入れ値（SKU別）、予約システム、
  個体在庫管理、発送・物流（送料テーブル）、**洗浄・検品SOPと人員手配の数字**、設備一覧、
  必要資金、5ヶ年損益・資金繰り・DSCR、代表者記入例、取引関係、立上げ90日まで。
  「本書だけで誰でも事業を再現できる」ことを目的とした実務マニュアル。
- `site/` — 顧客向けWebサイト（静的HTML/CSS/JS。ビルド不要）。
  ヒーロー、ラインナップ、利用フロー、料金、料金シミュレーター、予約フォーム（デモ）、FAQ。
- `deck/` — **日本政策金融公庫（国民生活事業／新規開業資金）向け 創業計画書デッキ**（全33スライド・HTML）。
  `deck/index.html` を開くと矢印キー/Spaceで送れるスライド。`P`キーでPDF印刷。
  仕入れ値、初期在庫、ユニットエコノミクス（全ティア）、予約/在庫/発送/洗浄の仕組み、
  必要資金と調達、5ヶ年損益、資金繰り、**DSCR**、事業の見通し（公庫様式 月平均）、
  **代表者プロフィール（記入例）**、取引関係、政策的意義、**創業計画書 対応表**まで網羅。
  `deck/VERREs_JFC_pitch.pdf` — 配布用PDF。

## ローカルで見る
`site/index.html` または `deck/index.html` をブラウザで開くだけ（依存なし）。

## 数値について
金額は意思決定・審査検証用のモデル値です。正式申込時は見積書・通帳（自己資金）・取引先内諾・
破損率実測で整合を取り、実際の仕入価格・運賃・需要で更新してください。
