> 「ただのグラスレンタル屋」と一線を画すための、独自資産に根ざした拡張モデル。
> 数値はモデル値（税抜）。既存の `BUSINESS_PLAN.md` / `OPERATIONS_MANUAL.md` と整合。

## 0. 中核アイデア ― 在庫が「3つの顔」を持つ（フライホイール）

VERREsの1脚のグラスは、同時に3つの役割を果たす。これが他社が真似しにくい構造的な「工夫」。

```
        ┌──────────────┐
        │   ① 貸す      │  レンタル収益（主）
        │  (Rent)       │
        └──────┬───────┘
               │ 利用データが貯まる
               ▼
        ┌──────────────┐        ┌──────────────┐
        │ ③ データを生む │ ───▶ │   ② 売る      │
        │ (Learn)       │  嗜好 │  (Sell)       │  Try&Buy送客＋中古販売
        └──────┬───────┘  に    └──────┬───────┘
               │ 基づく仕入最適化 ◀──────┘ 出口ができ在庫リスク低減
               ▼
        仕入が賢くなる → ①の収益性が上がる（フライホイール加速）
```

- **貸す**：本業のレンタル。
- **売る**：気に入った顧客にそのまま販売（新品はメーカー送客、使用個体は中古販売）＝**在庫の出口**。
- **データを生む**：品種×グラス×シーン×ワインの嗜好データ。レコメンド精度・仕入最適化・メーカー連携の原資。

**なぜ強いか**：レンタルが**試飲・販売チャネル**と**データ装置**を兼ねる。回せば回すほど、
出口（中古換価）と学習（仕入精度）が効いて、**在庫リスクが下がり収益性が上がる**。
メーカー/インポーターから見れば「**試して買わせる新チャネル**」＝協業の動機が生まれる。

## 1. 新サービス・ラインナップ（優先度順）

### ★1. サブスク「Monthly Cru（マンスリー・クリュ）」― C向け定期便
- **内容**：ソムリエ監修で「今月のグラス」を毎月（or 隔月）お届け。所有では出会えない名品を**毎月乗り換え**て体験。
  返却→翌月の新しいグラスへ。ワインのペアリング提案を同送。
- **狙い**：①LTV向上・解約率低 ②**前受（先払い）でキャッシュ先取り**＝負の運転資本を深める ③ブランドのファン化。
- **所有との決定的差**：買うと1種類で打ち止め。**レンタルだから"毎月違う名品を試せる"**＝サブスクの価値が最大化。

| プラン | 月額 | 内容 | 主原価/月 | 貢献/月 |
|---|---:|---|---:|---:|
| Casual（隔月） | ¥4,980 | ペア2脚・隔月でローテーション | ¥2,200 | **¥2,780** |
| Standard | ¥6,980 | ペア2脚・毎月／ペアリング提案 | ¥2,900 | **¥4,080** |
| Premium | ¥9,980 | ザルト等4脚・毎月 | ¥3,400 | **¥6,580** |

> 送料が主原価。**隔月配送・地域別・近郊集荷**で送料を平準化するのが採算の肝。
> LTV例（Standard・平均継続12ヶ月）：貢献 ¥4,080×12 = **¥48,960**。目標CAC<¥12,000で**LTV/CAC≧3**。

### ★2. Try & Buy（試して、気に入ったら買う）― 在庫の「出口」
- **内容**：レンタルで使った銘柄を**そのまま購入可能**。支払ったレンタル料の一部を購入代金に充当。
- **2つの収益**：
  1. **新品送客**：メーカー/正規代理店へ送客し**手数料10〜20%**（VERREsは在庫を持たずに販売益）。
  2. **中古販売**：回転を終えた**使用個体（検品合格の美品）を正規小売の50〜70%**で販売。
- **戦略的価値**：減価・回転落ちの個体に**換価の出口**ができ、**在庫リスクが激減**。資産回収率を確定させる。
  例：ザルト（仕入¥9,000／小売¥12,100）を**中古¥7,000**で販売。十分に回して稼いだ後なら**仕入回収済み＋売却益**。

### 3. ペアリング／ワイン連携（体験のキュレーション）
- インポーター・ワインショップと提携。グラス予約時に「**このワインにはこのグラス／このグラスにはこのワイン**」をレコメンド。
- 提携先からの**ドロップシップ同送**（酒類は提携先 or 酒販免許取得で対応）。
- 目玉企画：「**リーデル比較テイスティング・キット**」=同じワインを品種別グラス3種で飲み比べる体験を貸し出す。

### 4. eギフト「割れない・洗わない 高級グラス体験を贈る」
- 結婚祝い・記念日・昇進祝いに。**受け取った人が日時を指定**して受け取り。後片付け不要の体験を贈れる。
- 単価が高く季節需要を作れる。SNS映え＝低CACの獲得装置。

### 5. おうちワイン会パッケージ（高単価体験）
- グラス＋**出張ソムリエ**＋ワイン手配をワンストップ。グラスを入口に**体験単価を引き上げる**アップセル。

### 6. B2B2C 常備プラン（高級民泊・別荘・パーティスペース・ホテル）
- 施設に高級グラスを常備。チェックイン時に一級のグラスが用意されている体験。**安定的な定額収益**。

### 7. サステナビリティ可視化（ESG訴求）
- マイページに「あなたの利用で**使い捨てグラス○個・CO2○gを削減**」を表示。
- 法人イベント・企業向けで刺さる**CSR/ESGの訴求材料**。循環型ビジネスの可視化。

## 2. メーカー／インポーター連携の妙（CAPEXにも効く）

VERREsはメーカーにとって「**顧客に実際に使わせて買わせる**」唯一規模の体験チャネル。これを梃子に：
- **委託在庫（consignment）**：売れたら仕入計上 → **初期在庫CAPEXの一部を圧縮**できる余地。
- **販促協賛・共同企画**：新作グラスの体験キャンペーン費をメーカーが一部負担。
- **共同データ活用**：匿名集計した「品種×グラス×満足度」をメーカーに提供（インサイト対価）。

→ 資金面（公庫）への効果：**在庫の出口と追加収益源**があることで、**返済の確実性が増す**。

## 4. なぜ「工夫されたビジネス」に見えるか（要約）

1. **在庫が貸す・売る・学ぶの3役**＝レンタルが販売チャネルとデータ装置を兼ねる。
2. **Try&Buyで在庫に出口**＝資産型ビジネス最大の弱点（在庫リスク）を構造的に解消。
3. **サブスク×前受**＝LTVと負の運転資本を同時に強化。
4. **メーカー連携**＝CAPEX圧縮と協業の動機を設計的に生む。
5. **サステナ可視化**＝循環型の社会的意義を"見える化"し法人・政策と接続。

> いずれも**既存の物流・洗浄・在庫オペレーションの上に乗る**ため、追加投資は小さく、
> 立上げは「①B2B定額 → ②Try&Buy出口 → ③サブスク → ④メーカー連携」の順で段階導入する。
