設定

楽天市場 API （必須）

取得方法を見る（5分・無料）
  1. Rakuten Developers を開く
  2. 楽天IDでログイン（なければ新規登録・無料）
  3. 右上の 「+アプリID発行」 をクリック
  4. アプリ名: 価格比較（何でもOK）
  5. アプリURL: http://localhost（何でもOK）
  6. 「規約に同意して新規アプリを作成」をクリック
  7. 表示された 「アプリID/デベロッパーID」 をコピーして下の欄に貼り付け

Yahoo!ショッピング API （任意 - なくても使えます）

Yahoo!ショッピングの価格も比較したい場合に設定します。楽天だけでも使えます。

取得方法を見る（5分・無料）
  1. Yahoo!デベロッパー アプリ登録ページ を開く
  2. Yahoo! JAPAN IDでログイン
  3. 「アプリケーションの種類」→ サーバーサイド を選択
  4. 「アプリケーション名」→ 価格比較（何でもOK）
  5. 「サイトURL」→ http://localhost（何でもOK）
  6. メールアドレスを入力
  7. ガイドラインに同意して「確認」→「登録」
  8. 表示された 「Client ID」 をコピーして下の欄に貼り付け

※「シークレット」は使いません。「Client ID」だけでOKです。
