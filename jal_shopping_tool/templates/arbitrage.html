試算の前提

仕入れ側

  • 各ショップの検索結果の新品最安値を採用（出品者・在庫は要確認）
  • ポイント還元率は設定画面の値（楽天 / Yahoo!）とコジマ 1% を使用

Amazon（自己発送）

  • 相場: 検索結果の新品最安値（＝自分が合わせる価格）
  • 販売手数料: カテゴリ別 8〜15%（税抜）＋消費税 10%
  • 小口出品: 基本成約料 100円（税抜）/点。大口は月額制のため 0 で試算
  • 配送料: サイズ区分別の自己発送目安（FBA は未考慮）

メルカリ

  • 相場: 「売り切れ × 新品、未使用」の直近出品の中央値を優先。取得できない場合は出品中の最安値
  • 販売手数料 10%、らくらくメルカリ便（ネコポス 210円 / コンパクト 520円 / 60サイズ 750円 / 80サイズ 850円 / 100サイズ 1,050円）
  • メルカリは JavaScript 描画のため、Playwright 未導入環境では相場が取れないことがあります{% if not has_playwright %}（この環境: 未導入）{% endif %}

注意

  • 手数料・配送料は 2025〜2026 年時点の公開情報に基づく目安です
  • 営利目的で継続的に転売する場合は古物商許可が必要になることがあります。酒類・医薬品・チケット等は別途規制があります
  • Apple 等一部ブランドは Amazon で新品出品に承認が必要です。メルカリにも転売目的の出品を禁じる商品があります
